## 自己PR

**事業 KPI 起点の技術判断**
「技術のための技術」ではなく、売上・継続率・DAU といった事業指標から逆算して手段を選びます。広告収益のために TWA から WebView へ構成変更した判断、R の決定木分析から独自 KPI を設計した経験、効果が出なければ撤退する判断まで、施策をやりっぱなしにせず効果測定でクロージングする姿勢を一貫させています。

**未経験領域への立ち上げ力**
SDK 開発、決済端末アプリ、Android TV、Flutter、脆弱性診断——いずれも未経験から調査を始め、リリースや実証まで到達しました。ドキュメントを鵜呑みにせずソースを読み、「1,500ファイル修正が必要」と思われた問題を根本原因の特定で2ファイルの修正に収めるなど、根本原因に到達するまで調べ切ることを信条としています。

**仕組み化とチームへの還元**
リリース事故や属人化を人の注意力ではなく仕組みで防ぐことを重視し、CI/CD・静的解析・リリースワークフローを複数プロダクトに整備してきました。ペアプロ・モブプロによる技術移転、失敗事例を含む知見の文書化 (社内外あわせ多数の記事) で、個人の経験をチームの資産に変えています。

**AI 時代への適応力**
約1年の育休からの復帰後、AI エージェントが実装を担う開発スタイルの変化に短期間で適応し、Claude Code を前提としたフローで月次 PR 数を3ヶ月で 6 倍にしました。ブランクを「まっさらな目線」に転換し、環境構築のハマりどころをドキュメント化してチームに還元しています。
